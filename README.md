# Physics Lab — Experiment 03

## Photoelectric-effect animation

The Experiment 03 visual now embeds the supplied YouTube animation (`t_PiEdXzaMk`).

### Important: open the website through the included local server

Opening `experiment-03.html` directly with a `file://` URL can cause YouTube embed **Error 153**, because YouTube requires an HTTP referrer/context for the embedded player.

On Windows, double-click:

**`open-experiment-03.bat`**

The launcher starts Python's built-in local HTTP server and opens:

`http://127.0.0.1:8000/experiment-03.html#visual`

This gives the YouTube iframe a normal HTTP origin/referrer, allowing the animation to load inside the webpage.

If Python is not installed, install it from https://www.python.org/downloads/ and run the launcher again.

The video remains hosted by YouTube; the ZIP does not copy or redistribute the YouTube video file.
